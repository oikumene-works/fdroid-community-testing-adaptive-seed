# Guarded F-Droid Community Testing

This public repository is being prepared as a reusable starter kit for
independent community testing of third-party F-Droid new-app merge requests.
The starter kit itself has not yet been published. For now, this repository
contains a separately reviewed factual test report.

This is not an F-Droid project. Its reports are independent community evidence,
not F-Droid reviews, acceptance decisions, security audits, or endorsements.

## Published report

- [Social Deduction Game MR !47820 — Bounded Functional Test Report](reports/social-deduction-game-47820-bounded-functional-test.md)

The report identifies its exact candidate, scope, executor, environment,
observations, scope boundaries, and cleanup state. A bounded pass applies only
to the paths that were exercised.
