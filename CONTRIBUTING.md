# Contributing

Contributions should preserve the separation between read-only research,
executable actions, report review, and public mutations.

Before opening a change:

1. keep documentation and comments in English;
2. avoid adding third-party binaries, screenshots, raw logs, or copied app
   documentation;
3. keep examples fictional unless a real report has been separately reviewed;
4. run `./scripts/check-all.sh`; and
5. explain any change to an approval boundary or cleanup guarantee.

Do not include credentials, personal data, workstation paths, signed artifact
URLs, or private operational history. Security-sensitive reports should follow
`SECURITY.md` instead of a public issue.

By contributing original material, you agree that it may be distributed under
the repository's `0BSD` license.
